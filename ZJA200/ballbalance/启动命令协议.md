# 任务启动命令协议 (STM32 → 上位机)

## 概述

小车通过 **KEY1 启动某个任务**时，STM32 通过**串口1 (USART1)** 向上位机发送一条 **4 字节命令帧**，告知上位机当前执行的任务及其参数。

发送时机：任务启动 → 进入 RUNNING → 调用任务 `Init()` → 发送一次。

---

## 硬件参数

| 项目     | 值             |
| -------- | -------------- |
| 接口     | USART1         |
| TX 引脚  | PA9            |
| RX 引脚  | PA10           |
| 波特率   | 115200         |
| 数据格式 | 8N1            |

---

## 帧格式（4 字节）

```
[0xAA] [Byte1] [Byte2] [0xFF]
```

| 字节  | 字段   | 说明                     |
| :---: | ------ | ------------------------ |
| Byte0 | 帧头   | `0xAA`，固定             |
| Byte1 | 参数1  | 任务码 / 符号位（见下）  |
| Byte2 | 参数2  | 位置 / 数据（见下）      |
| Byte3 | 帧尾   | `0xFF`，固定             |

---

## 各任务命令帧

| 任务         | 命令帧          | 说明                       |
| ------------ | --------------- | -------------------------- |
| 题1 Ball Pos | `AA 02 05 FF`   | 固定                       |
| 题2 Straight | `AA 00 00 FF`   | 固定                       |
| 题3 Lap Balance | `AA 00 00 FF` | 固定                       |
| 题4 Ball Dist | `AA [00/01] XX FF` | 动态，XX = 所选指定位置 |

---

## 题4 参数说明

- **Byte1（符号位）**：`0x00` = 正，`0x01` = 负
- **Byte2（XX）**：指定位置的 **cm 绝对值（整数）**，直接写十六进制

### 示例

| 长按 KEY0 选择的指定位置 | 命令帧          |
| :----------------------: | --------------- |
| +9 cm                    | `AA 00 09 FF`   |
| -10 cm                   | `AA 01 0A FF`   |

> 注：XX 取所选位置（`g_task_param.ball_target`）的绝对值，不乘系数、不加偏移。

---

## 代码实现

- **发送函数**：`Task_SendFrame(cmd, len)`（[user/src/app/app_task.c](../user/src/app/app_task.c)）
  ```c
  static void Task_SendFrame(const uint8_t *cmd, uint8_t len)
  {
      HAL_UART_Transmit(&huart1, (uint8_t *)cmd, len, 100);
  }
  ```
- **各任务 Init 调用**：
  - 题1 `AppTask_BallPos_Init` → `AA 02 05 FF`
  - 题2 `AppTask_Straight_Init` → `AA 00 00 FF`
  - 题3 `AppTask_LapBalance_Init` → `AA 00 00 FF`
  - 题4 `AppTask_BallDist_Init` → `AA [符号位] [|ball_target|] FF`

- **注意**：USART1 与 X42S 步进电机共用（PA9 接步进 RX）。这些启动帧无 `0x6B` 帧尾、`0xAA` 非合法地址，步进电机会按无效帧忽略，不影响其正常工作。
