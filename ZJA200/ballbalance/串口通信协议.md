## 串口通信协议

**硬件参数**

| 项目     | 值           |
| -------- | ------------ |
| 接口     | UART1        |
| TX 引脚  | A19          |
| RX 引脚  | A18          |
| 设备路径 | `/dev/ttyS1` |
| 波特率   | 115200       |

**数据包格式（5 字节）**



```
┌────────┬────────┬────────┬────────┬──────────┐
│ Byte 0 │ Byte 1 │ Byte 2 │ Byte 3 │ Byte 4   │
├────────┼────────┼────────┼────────┼──────────┤
│ 0xAA   │ 0x04   │ sign   │ value  │ checksum │
│ 帧头    │ 长度    │ 符号位  │ X坐标   │ 校验和    │
└────────┴────────┴────────┴────────┴──────────┘
```

**各字段说明**

- **Byte 0 (0xAA)**：帧头，固定值
- **Byte 1 (0x04)**：数据长度，固定值
- **Byte 2 (sign)**：符号位，`0` = 正值/零，`1` = 负值
- **Byte 3 (value)**：X 坐标绝对值 = `round(|x_cm| × 10)`，上限 255，即最大传输 ±25.5cm
- **Byte 4 (checksum)**：前 4 字节求和取低 8 位

**举例**

| 小球位置 | 原始 x_cm | x_scaled | sign | value | 数据包           |
| -------- | --------- | -------- | ---- | ----- | ---------------- |
| 中心偏右 | +3.2      | 32       | 0x00 | 0x20  | `AA 04 00 20 EE` |
| 中心偏左 | -1.5      | 15       | 0x01 | 0x0F  | `AA 04 01 0F BE` |
| 正中心   | 0.0       | 0        | 0x00 | 0x00  | `AA 04 00 00 AE` |

**发送频率**：检测到球时**每帧发送一次**；**未检测到球时停止发送（不发帧）**。

> **丢球处理约定（重要）**：视觉丢球时**必须停止发包**，而不是发送 `x=0.0` 的帧。
> - STM32 侧（`ball_ctrl.c`）通过「200ms 无新帧」判定视觉超时（`BALL_CTRL_VISION_TIMEOUT_MS`），此时电机会回零保持、积分清零，防止小球失控。
> - 若丢球时发送 `x=0.0`，STM32 会一直收到新帧、超时保护永不触发，同时 PID 会误以为球在中心，持续驱动电机，极其危险。
