## 串口通信协议

**硬件参数**

| 项目     | 值           |
| -------- | ------------ |
| 接口     | UART1        |
| TX 引脚  | A19          |
| RX 引脚  | A18          |
| 设备路径 | `/dev/ttyS1` |
| 波特率   | 115200       |

**数据包格式**

> 当前视觉端发送 **新帧（7 字节：位置 + 加速度）**；STM32 同时兼容解析旧 5 字节帧（仅位置）。

**新帧（7 字节，位置 + 加速度）**

```
┌────────┬────────┬────────┬────────┬─────────┬─────────┬──────────┐
│ Byte 0 │ Byte 1 │ Byte 2 │ Byte 3 │ Byte 4  │ Byte 5  │ Byte 6   │
├────────┼────────┼────────┼────────┼─────────┼─────────┼──────────┤
│ 0xAA   │ 0x08   │ sign   │ value  │ a_sign  │ a_value │ checksum │
│ 帧头    │ 长度    │ 位置符号 │ 位置    │ 加速度符号│ 加速度   │ 校验和    │
└────────┴────────┴────────┴────────┴─────────┴─────────┴──────────┘
```

- **Byte 0 (0xAA)**：帧头，固定值
- **Byte 1 (0x08)**：长度字段，固定值（新帧）
- **Byte 2 (sign)**：位置符号位，`0` = 正/零，`1` = 负
- **Byte 3 (value)**：位置绝对值 = `round(|x_cm| × 10)`，上限 255，即 ±25.5cm
- **Byte 4 (a_sign)**：加速度符号位，`0` = 正/零，`1` = 负
- **Byte 5 (a_value)**：加速度绝对值 = `round(|accel| / 10)`，上限 255，即 ±2550 cm/s²
- **Byte 6 (checksum)**：前 6 字节求和取低 8 位

**举例（新帧）**

| 场景       | x_cm | accel      | 数据包                  |
| ---------- | ---- | ---------- | ----------------------- |
| 偏右匀速   | +3.2 | 0          | `AA 08 00 20 00 00 D2`  |
| 偏左向右加速 | -1.5 | +250 cm/s² | `AA 08 01 0F 00 19 DB`  |
| 中心减速   | 0.0  | -120 cm/s² | `AA 08 00 00 01 0C BF`  |

**旧帧（5 字节，仅位置，兼容）**

```
┌────────┬────────┬────────┬────────┬──────────┐
│ Byte 0 │ Byte 1 │ Byte 2 │ Byte 3 │ Byte 4   │
├────────┼────────┼────────┼────────┼──────────┤
│ 0xAA   │ 0x04   │ sign   │ value  │ checksum │
│ 帧头    │ 长度    │ 符号位  │ X坐标   │ 校验和    │
└────────┴────────┴────────┴────────┴──────────┘
```

- **Byte 1 (0x04)**：长度字段（旧帧）
- **Byte 4 (checksum)**：前 4 字节求和取低 8 位

**发送频率**：检测到球时**每帧发送一次**；**未检测到球时停止发送（不发帧）**。

> **丢球处理约定（重要）**：视觉丢球时**必须停止发包**，而不是发送 `x=0.0` 的帧。
> - STM32 侧（`ball_ctrl.c`）通过「200ms 无新帧」判定视觉超时（`BALL_CTRL_VISION_TIMEOUT_MS`），此时电机会回零保持、积分清零，防止小球失控。
> - 若丢球时发送 `x=0.0`，STM32 会一直收到新帧、超时保护永不触发，同时 PID 会误以为球在中心，持续驱动电机，极其危险。
